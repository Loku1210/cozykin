# Cookie（正面）

Cookie is a broad, dark long-haired tabby companion. Its front-facing idle keeps the golden eyes, dark forehead stripes, tufted ears, large ruff, full paws, and full patterned tail legible at runtime scale.

The Pack uses a normal non-looping stretch on wake and returns all finite actions to frontal `idle`. It contains no tongue behavior, source photography, photo metadata, embedded text, UI, scenery, or shadows.
